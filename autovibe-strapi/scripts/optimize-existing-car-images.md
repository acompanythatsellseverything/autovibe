# Оптимизация уже загруженных изображений Car (image, image_compra, image_empresas)

Новые загрузки в поля **image**, **image_compra**, **image_empresas** автомобиля автоматически сжимаются до ≤512 КБ. Для уже лежащих в медиабиблиотеке файлов можно один раз прогнать оптимизацию.

## Вариант 1: Вручную через админку

Для каждого автомобиля: откройте машину → в полях «Изображение» / «Изображение compra» / «Изображение empresas» нажмите **Заменить** и загрузите то же (или новое) изображение. При загрузке в эти поля файл автоматически сожмётся до 512 КБ.

## Вариант 2: Скрипт в Strapi Console

1. Остановите Strapi (если запущен).
2. Из папки `autovibe-strapi` выполните:
   ```bash
   npm run console
   ```
3. В открывшейся консоли вставьте и выполните код из файла `scripts/optimize-existing-car-images-snippet.js`.

Скрипт найдёт все Car с заполненными полями `image`, `image_compra`, `image_empresas`, для каждого файла >512 КБ сожмёт его и обновит файл на диске и запись в БД.
